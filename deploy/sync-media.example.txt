Медиа-папки «обьекты абк web» и «акбарс керамик для дилеров web» больше не в репозитории.

ВАЖНО: после git pull на сервере Git УДАЛИТ эти папки из рабочей копии (они выпали из коммита).
Перед pull сохраните медиа и верните после обновления, например:

  cd /var/www/brick-demo
  tar czf ~/brick-media.tgz "обьекты абк web" "акбарс керамик для дилеров web"
  git pull
  tar xzf ~/brick-media.tgz

Или временно переименуйте папки, сделайте pull, переименуйте обратно поверх пустых.

После git clone на сервере скопируйте медиа с ПК, например (подставьте пользователя и IP):

  rsync -avz --progress "./обьекты абк web/" root@ВАШ_IP:/var/www/brick-demo/обьекты\ абк\ web/
  rsync -avz --progress "./акбарс керамик для дилеров web/" root@ВАШ_IP:/var/www/brick-demo/акбарс\ керамик\ для\ дилеров\ web/

На Windows можно использовать WSL, cwRsync или WinSCP.

Снять папки с учёта Git (файлы на диске остаются), один раз у себя в корне проекта:

  git rm -r --cached "обьекты абк web" "акбарс керамик для дилеров web"
  git commit -m "chore: stop tracking catalog/gallery media folders"
  git push
